# Active implementation tasks

Every feature, fix or material refactor must have one directory:

`docs/active-task/YYYY-MM-DD_task-name/`

Required files:
- `TASK.md`
- `IMPLEMENTATION.md`

Create the task directory before implementation begins.

When the task is completed, tested and documentation has been synchronized, move the whole directory unchanged to:

`docs/history/YYYY-MM-DD_task-name/`

Do not leave completed work in `docs/active-task/`.

Templates are available under `docs/templates/task/`.
